## Install (one-time first-launch step)

Tape Looper is delivered directly by an independent developer, so macOS asks you
to confirm the first time you open it — normal, and only once:

1. Open the **.dmg** and drag **Tape Looper** to **Applications**.
2. Double-click it. macOS says *"can't be opened because it is not verified"* →
   click **Done**.
3. Open **System Settings → Privacy & Security**, scroll to **Security**,
   click **Open Anyway**, then confirm.

*(On macOS Ventura and earlier you can just right-click the app → Open → Open.)*
Still stuck? In Terminal: `xattr -dr com.apple.quarantine "/Applications/Tape Looper.app"`
